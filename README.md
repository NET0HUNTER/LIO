## ⚡ Overview

**LIO** is a lightweight, zero-dependency input/output stream processing toolkit designed for high-throughput data pipes, memory-efficient file buffering, and non-blocking asynchronous event dispatching.

---

## 🎯 Design Goals

- **Zero External Dependencies**: Engineered purely with core language primitives for maximum portability and zero supply-chain risk.
- **Bounded Memory Footprint**: Chunked streaming and backpressure handling to ensure gigabyte-scale datasets process safely within constrained container memory limits.
- **Cross-Platform Compatibility**: Consistent I/O abstraction across POSIX (Linux/macOS) and Windows runtime environments.
